# Adverbs — ಕ್ರಿಯಾವಿಶೇಷಣಗಳು (*kriyāviśēṣaṇagaḷu*)

Adverbs say **how**, **when**, **where** and **how often** something happens. English
makes many with *-ly*; Kannada makes them with **-ಆಗಿ** (*-āgi*). Many common adverbs,
though, are simply words of their own. This lesson covers both, grouped by meaning.

---

## 1. Making Adverbs with -ಆಗಿ (*-āgi*)

Add **-ಆಗಿ** (*-āgi*), literally "having become", to an adjective or noun. The joins are
the same as for -ಆದ (*-āda*) (see *Adjectives*, §4):

| Word ends in… | Join | Example |
| :--- | :--- | :--- |
| -ಅ (*-a*), a Sanskrit stem | add -ವ್- (*-v-*) | ಸುಲಭ (*sulabha*) → ಸುಲಭವಾಗಿ (*sulabhavāgi*) — easily |
| -ಅ (*-a*), a native adjective | add -ದ್- (*-d-*) | ಕೆಟ್ಟ (*keṭṭa*) → ಕೆಟ್ಟದಾಗಿ (*keṭṭadāgi*) — badly |
| -ಇ (*-i*) / -ಎ (*-e*) | add -ಯ್- (*-y-*) | ಸರಿ (*sari*) → ಸರಿಯಾಗಿ (*sariyāgi*) — properly |
| -ಉ (*-u*), a native word | drop the -ಉ (*-u*) | ಜೋರು (*jōru*) → ಜೋರಾಗಿ (*jōrāgi*) — loudly |
| ಚೆನ್ನ (*cenna*) | fixed form | ಚೆನ್ನಾಗಿ (*cennāgi*) — well |

| Adverb | Meaning | Example |
| :--- | :--- | :--- |
| ಚೆನ್ನಾಗಿ (*cennāgi*) | well, nicely | ಅವಳು ಚೆನ್ನಾಗಿ ಹಾಡ್ತಾಳೆ. (*Avaḷu cennāgi hāḍtāḷe.*) — She sings well. |
| ಸುಲಭವಾಗಿ (*sulabhavāgi*) | easily | ಕೆಲಸ ಸುಲಭವಾಗಿ ಆಯ್ತು. (*Kelasa sulabhavāgi āytu.*) — The job got done easily. |
| ಖುಷಿಯಾಗಿ (*khuṣiyāgi*) | happily | ಮಕ್ಕಳು ಖುಷಿಯಾಗಿ ಆಡ್ತಾ ಇದ್ದಾರೆ. (*Makkaḷu khuṣiyāgi āḍtā iddāre.*) — The children are playing happily. |
| ಜೋರಾಗಿ (*jōrāgi*) | loudly, hard | ಅವನು ಜೋರಾಗಿ ನಕ್ಕ. (*Avanu jōrāgi nakka.*) — He laughed loudly. |
| ನಿಧಾನವಾಗಿ (*nidhānavāgi*) | slowly | ನಿಧಾನವಾಗಿ ಮಾತಾಡಿ. (*Nidhānavāgi mātāḍi.*) — Please speak slowly. |
| ಸ್ಪಷ್ಟವಾಗಿ (*spaṣṭavāgi*) | clearly | ಸ್ಪಷ್ಟವಾಗಿ ಹೇಳಿ. (*Spaṣṭavāgi hēḷi.*) — Say it clearly. |
| ಸರಿಯಾಗಿ (*sariyāgi*) | properly; exactly | ಸರಿಯಾಗಿ ಕೂತ್ಕೊಳ್ಳಿ. (*Sariyāgi kūtkoḷḷi.*) — Sit properly. |
| ಜಾಗ್ರತೆಯಾಗಿ (*jāgrateyāgi*) | carefully | ಜಾಗ್ರತೆಯಾಗಿ ಹೋಗಿ. (*Jāgrateyāgi hōgi.*) — Go carefully. |
| ಕೆಟ್ಟದಾಗಿ (*keṭṭadāgi*) | badly | ಅವನು ಕೆಟ್ಟದಾಗಿ ಆಡಿದ. (*Avanu keṭṭadāgi āḍida.*) — He played badly. |
| ತಡವಾಗಿ (*taḍavāgi*) | late | ಇವತ್ತು ತಡವಾಗಿ ಎದ್ದೆ. (*Ivattu taḍavāgi edde.*) — I got up late today. |

### Feelings with -ಆಗಿ (*-āgi*)
-ಆಗಿ (*-āgi*) also says how someone did something: ಅವರು ಕೋಪವಾಗಿ ನೋಡಿದರು. (*Avaru kōpavāgi
nōḍidaru.*) — He (respectful) / they looked angrily. With ಇದೆ (*ide*), it gives a feeling:
ನನಗೆ ಬೇಜಾರಾಗಿದೆ (*nanage bējārāgide*) — I'm bored (see *Dative Constructions and Modals*).

### Adverbs in -ಗೆ (*-ge*)
A few adverbs end in -ಗೆ (*-ge*) instead:

* ಮೆಲ್ಲಗೆ (*mellage*) — softly, gently: ಮೆಲ್ಲಗೆ ಮಾತಾಡಿ. (*Mellage mātāḍi.*) — Speak softly.
* ನೆಟ್ಟಗೆ (*neṭṭage*) — straight: ನೆಟ್ಟಗೆ ಹೋಗಿ. (*Neṭṭage hōgi.*) — Go straight on.
* ಸುಮ್ಮನೆ (*summane*) — quietly; for no reason: ಸುಮ್ಮನೆ ಕೇಳ್ದೆ. (*Summane kēḷde.*) — I was
  just asking.

## 2. "I Am Well": ಚೆನ್ನಾಗಿ (*cennāgi*), Not ಚೆನ್ನ (*cenna*)

How you *are* is an adverb in Kannada: you exist **well**.

* ಹೇಗಿದ್ದೀರಿ? (*Hēgiddīri?*) — How are you? Spoken also ಹೇಗಿದ್ದೀರಾ? (*Hēgiddīrā?*)
* ✅ ಚೆನ್ನಾಗಿದ್ದೀನಿ. (*Cennāgiddīni.*) — I'm well. (ಚೆನ್ನಾಗಿ (*cennāgi*) + ಇದ್ದೀನಿ (*iddīni*))
* ❌ ಚೆನ್ನ ಇದ್ದೀನಿ (*cenna iddīni*)

For a **thing**, use ಚೆನ್ನಾಗಿದೆ (*cennāgide*): ಕಾಫಿ ಚೆನ್ನಾಗಿದೆ. (*Kāphi cennāgide.*) — The
coffee is good.

## 3. How Much: Degree and Limiting Words

| Adverb | Meaning | Example |
| :--- | :--- | :--- |
| ತುಂಬಾ (*tumbā*) | very, a lot | ಊಟ ತುಂಬಾ ಚೆನ್ನಾಗಿದೆ. (*Ūṭa tumbā cennāgide.*) — The food is very good. |
| ಬಹಳ (*bahaḷa*) | very (more formal) | ಇದು ಬಹಳ ಮುಖ್ಯ. (*Idu bahaḷa mukhya.*) — This is very important. |
| ಸ್ವಲ್ಪ (*svalpa*) | a little | ಸ್ವಲ್ಪ ಇರಿ. (*Svalpa iri.*) — Wait a moment. |
| ಜಾಸ್ತಿ (*jāsti*) | more; too much | ಬೆಲೆ ಜಾಸ್ತಿ. (*Bele jāsti.*) — The price is too high. |
| ಕಡಿಮೆ (*kaḍime*) | less | ಖಾರ ಕಡಿಮೆ ಹಾಕಿ. (*Khāra kaḍime hāki.*) — Make it less spicy. |
| ಸುಮಾರು (*sumāru*) | about, roughly | ಸುಮಾರು ಹತ್ತು ಜನ ಬಂದ್ರು. (*Sumāru hattu jana bandru.*) — About ten people came. |
| ಮಾತ್ರ (*mātra*) | only (after the word) | ಅವನು ಮಾತ್ರ ಬಂದ. (*Avanu mātra banda.*) — Only he came. |
| ಬರೀ (*barī*) | just, nothing but | ಬರೀ ಅನ್ನ ತಿಂದೆ. (*Barī anna tinde.*) — I ate just rice. |
| ಕೂಡ (*kūḍa*) / -ಊ (*-ū*) | also, too | ನಾನು ಕೂಡ ಬರ್ತೀನಿ. (*Nānu kūḍa bartīni.*) = ನಾನೂ ಬರ್ತೀನಿ. (*Nānū bartīni.*) — I'll come too. |

## 4. When: Time Adverbs

| Adverb | Meaning | Adverb | Meaning |
| :--- | :--- | :--- | :--- |
| ಈಗ (*īga*) | now | ಆಗ (*āga*) | then |
| ಇವತ್ತು (*ivattu*) | today | ನಿನ್ನೆ (*ninne*) | yesterday |
| ನಾಳೆ (*nāḷe*) | tomorrow | ಮೊನ್ನೆ (*monne*) | the day before yesterday |
| ನಾಡಿದ್ದು (*nāḍiddu*) | the day after tomorrow | ಬೆಳಿಗ್ಗೆ (*beḷigge*) | (in the) morning |
| ಮಧ್ಯಾಹ್ನ (*madhyāhna*) | (in the) afternoon | ಸಂಜೆ (*sañje*) | (in the) evening |
| ರಾತ್ರಿ (*rātri*) | (at) night | ಆಮೇಲೆ (*āmēle*) | later, afterwards |
| ಮೊದಲು (*modalu*) | first, before | ಮುಂಚೆ (*muñce*) | earlier, before |
| ಆಗಲೇ (*āgalē*) | already | ಇನ್ನೂ (*innū*) | still; (not) yet |
| ಮತ್ತೆ (*matte*) | again | ತಕ್ಷಣ (*takṣaṇa*) | immediately |
| ಕೊನೆಗೆ (*konege*) | finally | ಬೇಗ (*bēga*) | early; quickly |

* ಅವರು ಆಗಲೇ ಹೋದ್ರು. (*Avaru āgalē hōdru.*) — They've already left.
* ಮಳೆ ಇನ್ನೂ ಬರ್ತಾ ಇದೆ. (*Maḷe innū bartā ide.*) — It's still raining.
* ಮತ್ತೆ ಸಿಗೋಣ. (*Matte sigōṇa.*) — See you again.
* ಕೊನೆಗೆ ಬಸ್ ಬಂತು. (*Konege bas bantu.*) — Finally the bus came.

Time words need no suffix: ಬೆಳಿಗ್ಗೆ ಬನ್ನಿ (*beḷigge banni*) — come in the morning. For
"before / after X", see *Case Endings vs. Prepositions*.

## 5. How Often: Frequency

| Adverb | Meaning | Example |
| :--- | :--- | :--- |
| ಯಾವಾಗಲೂ (*yāvāgalū*) | always | ಅವಳು ಯಾವಾಗಲೂ ನಗ್ತಾ ಇರ್ತಾಳೆ. (*Avaḷu yāvāgalū nagtā irtāḷe.*) — She's always smiling. |
| ದಿನಾ (*dinā*) | every day | ದಿನಾ ವಾಕಿಂಗ್ ಹೋಗ್ತೀನಿ. (*Dinā vākiṅg hōgtīni.*) — I go for a walk every day. |
| ಆಗಾಗ (*āgāga*) | now and then | ನಾನು ಆಗಾಗ ಮೈಸೂರಿಗೆ ಹೋಗ್ತೀನಿ. (*Nānu āgāga Maisūrige hōgtīni.*) — I go to Mysore now and then. |
| ಕೆಲವು ಸಲ (*kelavu sala*) | sometimes | ಕೆಲವು ಸಲ ಬಸ್ ತಡ ಆಗುತ್ತೆ. (*Kelavu sala bas taḍa āgutte.*) — Sometimes the bus is late. |
| ಒಂದು ಸಲ (*ondu sala*) | once | ಒಂದು ಸಲ ನೋಡಿ. (*Ondu sala nōḍi.*) — Take a look (once). |
| ಅಪರೂಪಕ್ಕೆ (*aparūpakke*) | rarely | ಅವರು ಅಪರೂಪಕ್ಕೆ ಬರ್ತಾರೆ. (*Avaru aparūpakke bartāre.*) — They rarely come. |
| ಯಾವತ್ತೂ (*yāvattū*) + negative | never | ನಾನು ಯಾವತ್ತೂ ಅಲ್ಲಿಗೆ ಹೋಗಿಲ್ಲ. (*Nānu yāvattū allige hōgilla.*) — I've never been there. |

## 6. Where: Place Adverbs

| Adverb | Meaning | Adverb | Meaning |
| :--- | :--- | :--- | :--- |
| ಇಲ್ಲಿ (*illi*) | here | ಅಲ್ಲಿ (*alli*) | there |
| ಇಲ್ಲೇ (*illē*) | right here | ಎಲ್ಲಿ (*elli*) | where |
| ಮೇಲೆ (*mēle*) | up, upstairs | ಕೆಳಗೆ (*keḷage*) | down, downstairs |
| ಒಳಗೆ (*oḷage*) | inside | ಹೊರಗೆ (*horage*) | outside |
| ಮುಂದೆ (*munde*) | ahead, in front | ಹಿಂದೆ (*hinde*) | behind; back |
| ಹತ್ತಿರ (*hattira*) | near | ದೂರ (*dūra*) | far |

* For movement, add the dative or ablative: ಇಲ್ಲಿಗೆ ಬಾ (*illige bā*) — come here;
  ಇಲ್ಲಿಂದ ಹೋಗು (*illinda hōgu*) — go away from here.
* ನಮ್ಮ ಮನೆ ಇಲ್ಲಿಂದ ದೂರ ಇಲ್ಲ. (*Namma mane illinda dūra illa.*) — Our house isn't far from here.
* Most of these also work as postpositions after a noun (ಮನೆಯ ಒಳಗೆ (*maneya oḷage*) —
  inside the house). See *Case Endings vs. Prepositions*.

---

## 7. Like This, Like That: ಹೀಗೆ (*hīge*), ಹಾಗೆ (*hāge*), ಹೇಗೆ (*hēge*)

* ಹೀಗೆ ಮಾಡಿ. (*Hīge māḍi.*) — Do it like this.
* ಹಾಗೆ ಹೇಳಬೇಡಿ. (*Hāge hēḷabēḍi.*) — Don't say that.
* ಇದನ್ನ ಹೇಗೆ ಮಾಡೋದು? (*Idanna hēge māḍōdu?*) — How do you do this?
* ಹಾಗೇ ಇರಲಿ. (*Hāgē irali.*) — Leave it as it is.

## 8. Question Adverbs

| Adverb | Meaning | Example |
| :--- | :--- | :--- |
| ಯಾಕೆ (*yāke*) | why | ಯಾಕೆ ಲೇಟ್? (*Yāke lēṭ?*) — Why are you late? |
| ಯಾವಾಗ (*yāvāga*) | when | ಯಾವಾಗ ಬರ್ತೀರಾ? (*Yāvāga bartīrā?*) — When will you come? |
| ಎಲ್ಲಿ (*elli*) | where | ಎಲ್ಲಿ ಇದ್ದೀರಾ? (*Elli iddīrā?*) — Where are you? |
| ಹೇಗೆ (*hēge*) | how | ಹೇಗೆ ಬಂದ್ರಿ? (*Hēge bandri?*) — How did you come? |
| ಎಷ್ಟು (*eṣṭu*) | how much | ಎಷ್ಟು ಆಯ್ತು? (*Eṣṭu āytu?*) — How much is it? |

## 9. Sentence Adverbs: Probably, Definitely, By the Way

| Adverb | Meaning | Example |
| :--- | :--- | :--- |
| ಬಹುಶಃ (*bahuśaḥ*) | probably | ಬಹುಶಃ ನಾಳೆ ಬರ್ತೀನಿ. (*Bahuśaḥ nāḷe bartīni.*) — I'll probably come tomorrow. |
| ಖಂಡಿತ (*khaṇḍita*) | definitely | ಖಂಡಿತ ಬರ್ತೀನಿ. (*Khaṇḍita bartīni.*) — I'll definitely come. |
| ನಿಜವಾಗಲೂ (*nijavāgalū*) | really, honestly | ನಿಜವಾಗಲೂ? (*Nijavāgalū?*) — Really? |
| ಒಂದು ವೇಳೆ (*ondu vēḷe*) | perhaps; in case | ಒಂದು ವೇಳೆ ಮಳೆ ಬಂದ್ರೆ… (*Ondu vēḷe maḷe bandre…*) — In case it rains… |
| ಅಂದ ಹಾಗೆ (*anda hāge*) | by the way | ಅಂದ ಹಾಗೆ, ನಾಳೆ ರಜಾ ಇದೆಯಾ? (*Anda hāge, nāḷe rajā ideyā?*) — By the way, is tomorrow a holiday? |
| ಹೇಗೂ (*hēgū*) | anyway | ಹೇಗೂ ಅಲ್ಲಿಗೆ ಹೋಗ್ತಾ ಇದ್ದೀನಿ. (*Hēgū allige hōgtā iddīni.*) — I'm going there anyway. |

## 10. Doubling and Emphasis

* **Doubling** stresses or spreads out the action: ಬೇಗ ಬೇಗ (*bēga bēga*) — hurry up;
  ಸ್ವಲ್ಪ ಸ್ವಲ್ಪ (*svalpa svalpa*) — little by little; ನಿಧಾನ ನಿಧಾನವಾಗಿ (*nidhāna nidhānavāgi*) —
  gradually.
* **-ಏ** (*-ē*) means "right, very": ಈಗಲೇ (*īgalē*) — right now; ಇಲ್ಲೇ (*illē*) — right here;
  ಅದೇ (*adē*) — that very one. ಈಗಲೇ ಬಾ. (*Īgalē bā.*) — Come right now.

---

## 11. Where Adverbs Go

Adverbs come **before the verb**. A safe order is **time → place → manner → verb**:

* ನಾನು ನಾಳೆ ಆಫೀಸಿಗೆ ಬೇಗ ಹೋಗ್ತೀನಿ. (*Nānu nāḷe āphīsige bēga hōgtīni.*) — I'll go to the
  office early tomorrow.

Time words often come first for emphasis: ನಾಳೆ ನಾನು (*nāḷe nānu*)… See *Sentence Structure
and Word Order*.

## 12. Common Mistakes

* ❌ ಚೆನ್ನ ಇದ್ದೀನಿ (*cenna iddīni*) → ✅ ಚೆನ್ನಾಗಿದ್ದೀನಿ (*cennāgiddīni*) — I'm well.
* ❌ ಚೆನ್ನವಾಗಿ (*cennavāgi*) → ✅ ಚೆನ್ನಾಗಿ (*cennāgi*).
* ❌ ಜೋರುವಾಗಿ (*jōruvāgi*) → ✅ ಜೋರಾಗಿ (*jōrāgi*). Native -ಉ (*-u*) drops.
* ❌ ಮಾತ್ರ ಕಾಫಿ (*mātra kāphi*) → ✅ ಕಾಫಿ ಮಾತ್ರ (*kāphi mātra*) — only coffee. ಮಾತ್ರ
  (*mātra*) comes after the word.
* For "never", use ಯಾವತ್ತೂ (*yāvattū*) + a negative verb, not ಯಾವಾಗಲೂ (*yāvāgalū*), "always".

## 13. Quick Reference

| Question | Answer words |
| :--- | :--- |
| How? | -ಆಗಿ (*-āgi*) adverbs, ಹೀಗೆ / ಹಾಗೆ (*hīge / hāge*), ಮೆಲ್ಲಗೆ (*mellage*) |
| How much? | ತುಂಬಾ, ಸ್ವಲ್ಪ, ಜಾಸ್ತಿ, ಕಡಿಮೆ, ಮಾತ್ರ (*tumbā, svalpa, jāsti, kaḍime, mātra*) |
| When? | ಈಗ, ಆಗ, ಇವತ್ತು, ನಾಳೆ, ಆಮೇಲೆ, ಆಗಲೇ (*īga, āga, ivattu, nāḷe, āmēle, āgalē*) |
| How often? | ಯಾವಾಗಲೂ, ದಿನಾ, ಆಗಾಗ, ಕೆಲವು ಸಲ (*yāvāgalū, dinā, āgāga, kelavu sala*) |
| Where? | ಇಲ್ಲಿ, ಅಲ್ಲಿ, ಒಳಗೆ, ಹೊರಗೆ, ಮೇಲೆ, ಕೆಳಗೆ (*illi, alli, oḷage, horage, mēle, keḷage*) |

## For Hindi Speakers

* Hindi *-se* adverbs often match -ಆಗಿ (*-āgi*): *dhīre se* is ನಿಧಾನವಾಗಿ (*nidhānavāgi*);
  *acchī tarah* is ಚೆನ್ನಾಗಿ (*cennāgi*).
* Hindi *sirf* comes before the word (*sirf cāy*); Kannada ಮಾತ್ರ (*mātra*) comes after
  (ಟೀ ಮಾತ್ರ (*ṭī mātra*)).
* Hindi *bhī* is ಕೂಡ (*kūḍa*) or -ಊ (*-ū*); *kabhī nahī̃* is ಯಾವತ್ತೂ (*yāvattū*) + negative.
