# Conditional — ಮಾಡಿದರೆ, ಮಾಡದಿದ್ದರೆ (*māḍidare, māḍadiddare*)

Kannada has no separate word for "if". The "if" is an **ending on the verb** of the
"if" clause, and that clause comes **first**. The verb of the second ("then") clause
decides whether the meaning is real, possible, or contrary to fact.

---

## 1. How the "If" Form Is Built

### Positive: "If (one) does"
> **Past stem** + **-ಅರೆ** (*-are*) → ಮಾಡಿದ್ (*māḍid*) + ಅರೆ (*are*) → ಮಾಡಿದರೆ (*māḍidare*)

| Root | Past stem | Formal | Spoken | Meaning |
| :--- | :--- | :--- | :--- | :--- |
| ಮಾಡು (*māḍu*) | ಮಾಡಿದ್ (*māḍid*) | ಮಾಡಿದರೆ (*māḍidare*) | ಮಾಡಿದ್ರೆ (*māḍidre*) | if (one) does |
| ಬರು (*baru*) | ಬಂದ್ (*band*) | ಬಂದರೆ (*bandare*) | ಬಂದ್ರೆ (*bandre*) | if (one) comes |
| ಹೋಗು (*hōgu*) | ಹೋದ್ (*hōd*) | ಹೋದರೆ (*hōdare*) | ಹೋದ್ರೆ (*hōdre*) | if (one) goes |
| ಕುಡಿ (*kuḍi*) | ಕುಡಿದ್ (*kuḍid*) | ಕುಡಿದರೆ (*kuḍidare*) | ಕುಡಿದ್ರೆ (*kuḍidre*) | if (one) drinks |
| ಇರು (*iru*) | ಇದ್ದ್ (*idd*) | ಇದ್ದರೆ (*iddare*) | ಇದ್ರೆ (*idre*) | if (one) is, if there is |
| ಸಿಗು (*sigu*) | ಸಿಕ್ಕ್ (*sikk*) | ಸಿಕ್ಕರೆ (*sikkare*) | ಸಿಕ್ರೆ (*sikre*) | if (one) gets / finds |
| ಆಗು (*āgu*) | ಆದ್ (*ād*) | ಆದರೆ (*ādare*) | ಆದ್ರೆ (*ādre*) | if it happens, if it is |

The past stem is the same one used for the past tense, irregulars included (see *Past
Tense*, §3). Despite the past stem, the form is **not** past: ಬಂದರೆ (*bandare*) means "if
(one) comes", now or later.

### Negative: "If (one) doesn't"
> **Infinitive stem** (root + -ಅ (*-a*)) + **-ದಿದ್ದರೆ** (*-diddare*) → ಮಾಡದಿದ್ದರೆ (*māḍadiddare*)

| Root | Formal | Spoken | Meaning |
| :--- | :--- | :--- | :--- |
| ಮಾಡು (*māḍu*) | ಮಾಡದಿದ್ದರೆ (*māḍadiddare*) | ಮಾಡದಿದ್ರೆ / ಮಾಡ್ದೇ ಇದ್ರೆ (*māḍadidre / māḍdē idre*) | if (one) doesn't do |
| ಬರು (*baru*) | ಬರದಿದ್ದರೆ (*baradiddare*) | ಬರದಿದ್ರೆ (*baradidre*) | if (one) doesn't come |
| ಹೋಗು (*hōgu*) | ಹೋಗದಿದ್ದರೆ (*hōgadiddare*) | ಹೋಗದಿದ್ರೆ (*hōgadidre*) | if (one) doesn't go |
| ತಿನ್ನು (*tinnu*) | ತಿನ್ನದಿದ್ದರೆ (*tinnadiddare*) | ತಿನ್ನದಿದ್ರೆ (*tinnadidre*) | if (one) doesn't eat |
| ಇರು (*iru*) | ಇಲ್ಲದಿದ್ದರೆ (*illadiddare*) | ಇಲ್ಲದಿದ್ರೆ (*illadidre*) | if (one) isn't / there isn't |

* *Literally:* "if (one) is in the state of not doing". It is the "without" form, ಮಾಡದೆ
  (*māḍade*), plus ಇದ್ದರೆ (*iddare*) (see *Negation*, §6).
* You will also see the literary ಬಾರದಿದ್ದರೆ (*bāradiddare*) for ಬರದಿದ್ದರೆ (*baradiddare*).

### "If (one) had done"
> **Past participle** + **ಇದ್ದರೆ** (*iddare*) → ಹೇಳಿದ್ದರೆ (*hēḷiddare*) — if (you) had told

Spoken Kannada often uses plain ಹೇಳಿದ್ರೆ (*hēḷidre*) here, or the explicit ಹೇಳಿದ್ದಿದ್ರೆ
(*hēḷiddidre*). See §4D.

**Every "if" form is the same for every person**: ನಾನು / ನೀವು / ಅವರು ಬಂದರೆ (*nānu / nīvu /
avaru bandare*) — if I / you / they come.

## 2. "If It Is …": Nouns and Adjectives

| Meaning | Pattern | Example |
| :--- | :--- | :--- |
| if (it) is a X / becomes X | noun + ಆದರೆ (*ādare*) | ನೀನು ಡಾಕ್ಟರ್ ಆದ್ರೆ… (*Nīnu ḍākṭar ādre…*) — If you become a doctor… |
| if (it) is (true, so) | noun / adjective + ಆದರೆ (*ādare*) | ಇದು ನಿಜ ಆದ್ರೆ… (*Idu nija ādre…*) — If this is true… |
| if there is / if (it) is (somewhere, in a state) | ಇದ್ದರೆ (*iddare*) | ಸಮಯ ಇದ್ರೆ… (*Samaya idre…*) — If there's time…; ಹುಷಾರಾಗಿದ್ರೆ… (*Huṣārāgidre…*) — If (you're) well… |
| if (it) isn't a X | ಅಲ್ಲದಿದ್ದರೆ (*alladiddare*) | ಅವನು ಡಾಕ್ಟರ್ ಅಲ್ಲದಿದ್ರೆ… (*Avanu ḍākṭar alladidre…*) — If he isn't a doctor… |
| if there isn't | ಇಲ್ಲದಿದ್ದರೆ (*illadiddare*) | ಹಾಲು ಇಲ್ಲದಿದ್ರೆ ಮೊಸರು ತಗೊಂಡು ಬಾ. (*Hālu illadidre mosaru tagoṇḍu bā.*) — If there's no milk, bring curd. |

## 3. "Even If": -ಅರೂ (*-arū*)

Add **-ಊ** (*-ū*) ("even, also") to the "if" form.

* **Even if:** ಮಳೆ ಬಂದ್ರೂ ಹೋಗ್ತೀನಿ. (*Maḷe bandrū hōgtīni.*) — I'll go even if it rains.
  Formal: ಬಂದರೂ (*bandarū*).
* **Although:** ಜ್ವರ ಇದ್ದರೂ ಅವನು ಆಫೀಸಿಗೆ ಹೋದ. (*Jvara iddarū avanu āphīsige hōda.*) — Although
  he had a fever, he went to the office.
* **Even if not:** ಬರದಿದ್ದರೂ (*baradiddarū*), spoken ಬರದಿದ್ರೂ (*baradidrū*).
* **Whether or not:** ಅವನು ಬಂದ್ರೂ ಬರದಿದ್ರೂ ನಾವು ಹೋಗ್ತೀವಿ. (*Avanu bandrū baradidrū nāvu
  hōgtīvi.*) — Whether he comes or not, we're going.
* **Whoever, whatever, however much:** question word + -ಅರೂ (*-arū*):

| Kannada | Meaning |
| :--- | :--- |
| ಯಾರು ಬಂದರೂ (*yāru bandarū*) | whoever comes |
| ಏನು ಮಾಡಿದರೂ (*ēnu māḍidarū*) | whatever (you) do |
| ಎಲ್ಲಿ ಹೋದರೂ (*elli hōdarū*) | wherever (you) go |
| ಎಷ್ಟು ಹೇಳಿದ್ರೂ (*eṣṭu hēḷidrū*) | no matter how often (I) tell |

ಎಷ್ಟು ಹೇಳಿದ್ರೂ ಅವನು ಕೇಳಲ್ಲ. (*Eṣṭu hēḷidrū avanu kēḷalla.*) — No matter how often I tell
him, he doesn't listen.

### "Only If": -ಅರೆ ಮಾತ್ರ (*-are mātra*)
* ಟಿಕೆಟ್ ಇದ್ದರೆ ಮಾತ್ರ ಒಳಗೆ ಬಿಡ್ತಾರೆ. (*Ṭikeṭ iddare mātra oḷage biḍtāre.*) — They only let
  you in if you have a ticket.

## 4. The "Then" Clause

The "if" clause can stay the same; the **"then" verb** sets the meaning.

### A. General Truth: "If X, Y happens"
"Then" verb in the **present**.

* ಬೆಳಿಗ್ಗೆ ಬೇಗ ಹೊರಟ್ರೆ ಟ್ರಾಫಿಕ್ ಇರಲ್ಲ. (*Beḷigge bēga horaṭre ṭrāphik iralla.*) — If you
  leave early, there's no traffic.
* ಹಾಲನ್ನ ಫ್ರಿಜ್‌ನಲ್ಲಿ ಇಡದಿದ್ರೆ ಹಾಳಾಗುತ್ತೆ. (*Hālanna phrijnalli iḍadidre hāḷāgutte.*) — If you
  don't keep milk in the fridge, it goes off.

### B. Future: "If X, I will Y"
"Then" verb in the **present / future**.

* ನಾಳೆ ಮಳೆ ಬಂದ್ರೆ, ನಾನು ಮನೇಲೇ ಇರ್ತೀನಿ. (*Nāḷe maḷe bandre, nānu manēlē irtīni.*) — If it
  rains tomorrow, I'll stay at home.
* *Formal:* ನಾಳೆ ಮಳೆ ಬಂದರೆ, ನಾನು ಮನೆಯಲ್ಲಿ ಇರುತ್ತೇನೆ. (*Nāḷe maḷe bandare, nānu maneyalli
  iruttēne.*)

### C. Command or Suggestion: "If X, do Y"
"Then" verb is a **command** or "let's".

* ಏನಾದ್ರೂ ಬೇಕಾದ್ರೆ ಫೋನ್ ಮಾಡಿ. (*Ēnādrū bēkādre phōn māḍi.*) — If you need anything, call.
* ಮಳೆ ಬಂದ್ರೆ ಛತ್ರಿ ತಗೊಂಡು ಹೋಗು. (*Maḷe bandre chatri tagoṇḍu hōgu.*) — If it rains, take an
  umbrella.
* ಸಮಯ ಸಿಕ್ಕರೆ ಸಿನಿಮಾಗೆ ಹೋಗೋಣ. (*Samaya sikkare sinimāge hōgōṇa.*) — If we get time, let's go
  to a film.

### D. Contrary to Fact: "If X had happened, Y would have happened"
"Then" verb in the **past continuous / "used to"** form, -ಉತ್ತಿದ್ದ (*-uttidda*), spoken
-ತಿದ್ದ (*-tidda*). This "then" verb is what marks the sentence as unreal.

The "if" verb can be the plain form, or the explicit "had" form (§1) for clarity:

* *Formal:* ನೀನು ನನಗೆ ಹೇಳಿದ್ದರೆ, ನಾನು ಸಹಾಯ ಮಾಡುತ್ತಿದ್ದೆ. (*Nīnu nanage hēḷiddare, nānu
  sahāya māḍuttidde.*) — If you had told me, I would have helped.
* *Spoken:* ನೀನು ಹೇಳಿದ್ದಿದ್ರೆ, ನಾನು ಸಹಾಯ ಮಾಡ್ತಿದ್ದೆ. (*Nīnu hēḷiddidre, nānu sahāya
  māḍtidde.*)
* *Negative:* ಬಸ್ ತಡವಾಗದಿದ್ದರೆ, ನಾನು ಸಮಯಕ್ಕೆ ಸರಿಯಾಗಿ ಬರುತ್ತಿದ್ದೆ. (*Bas taḍavāgadiddare, nānu
  samayakke sariyāgi baruttidde.*) — If the bus hadn't been late, I'd have arrived on time.

**Wishes** use the same shape with ಚೆನ್ನಾಗಿತ್ತು (*cennāgittu*), "it would have been nice":

* ಇನ್ನೂ ಸ್ವಲ್ಪ ಸಮಯ ಇದ್ದಿದ್ದರೆ ಚೆನ್ನಾಗಿತ್ತು. (*Innū svalpa samaya iddiddare cennāgittu.*) —
  If only there had been a bit more time.
* ನನಗೆ ಕಾರು ಇದ್ದಿದ್ರೆ ಚೆನ್ನಾಗಿರ್ತಿತ್ತು. (*Nanage kāru iddidre cennāgirtittu.*) — It would be
  nice if I had a car.

### E. Formal Prediction: "If X, then Y will happen" — -ಉವುದು (*-uvudu*)
In formal or written Kannada, the "then" clause can use **root + -ಉವುದು** (*-uvudu*)
instead of -ಉತ್ತದೆ (*-uttade*). It states the expected, general consequence. It is **not**
a "may": for possibility, use -ಬಹುದು (*-bahudu*) (see *Dative Constructions and Modals*).

* **Formula:** root + -ಉವುದು (*-uvudu*): ಆಗು (*āgu*) → ಆಗುವುದು (*āguvudu*), ಬರು (*baru*) →
  ಬರುವುದು (*baruvudu*), ಮಾಡು (*māḍu*) → ಮಾಡುವುದು (*māḍuvudu*).
* **Only for "it":** the subject must be 3rd-person neuter singular, a thing or a situation.
* **Example:** ನೀವು ಓಪಿಯಾಯ್ಡ್‌ಗಳನ್ನು ತೆಗೆದುಕೊಂಡರೆ, ಅವುಗಳನ್ನು ನಿಲ್ಲಿಸಲು ಕಷ್ಟವಾಗುವುದು. (*Nīvu
  ōpiyāyḍgaḷannu tegedukoṇḍare, avugaḷannu nillisalu kaṣṭavāguvudu.*) — If you take
  opioids, it will be difficult to stop them.

| "Then" clause | Register | Meaning |
| :--- | :--- | :--- |
| ಕಷ್ಟವಾಗುತ್ತದೆ (*kaṣṭavāguttade*) | Neutral standard | It will be / is difficult |
| ಕಷ್ಟವಾಗುವುದು (*kaṣṭavāguvudu*) | Formal / written | It will be difficult (general prediction) |
| ಕಷ್ಟವಾಗಬಹುದು (*kaṣṭavāgabahudu*) | Any | It **may** be difficult |
| ಕಷ್ಟ ಆಗುತ್ತೆ (*kaṣṭa āgutte*) | Spoken | It'll be difficult |

* **Same shape as the verbal noun:** ಓದುವುದು ಒಳ್ಳೆಯದು (*ōduvudu oḷḷeyadu*), "Reading is good"
  (see *Impersonal Verbs*). Position tells them apart: as the final verb of the "then"
  clause, it is the prediction.
* **You already know its negative:** -ಉವುದಿಲ್ಲ (*-uvudilla*): ಹೋಗುವುದಿಲ್ಲ (*hōguvudilla*),
  "won't go", is this form + ಇಲ್ಲ (*illa*).
* **Don't mix registers:** spoken forms like ತೊಗೊಂಡರೆ (*togoṇḍare*) or ನಿಲ್ಲಿಸಲಿಕ್ಕೆ
  (*nillisalikke*) sit oddly beside the formal -ಉವುದು (*-uvudu*); pair it with ತೆಗೆದುಕೊಂಡರೆ
  (*tegedukoṇḍare*) / ನಿಲ್ಲಿಸಲು (*nillisalu*).

## 5. The Two ಆದರೆ (*ādare*)s

**ಆದರೆ** (*ādare*) appears in two very different roles.

### 1. The Conditional "If"
* **Origin:** ಆಗು (*āgu*), "to become" + -ಅರೆ (*-are*) = ಆದರೆ (*ādare*).
* **Meaning:** if it happens, if it is.
* ಮಳೆ **ಆದರೆ**, ನಾವು ಹೋಗುವುದಿಲ್ಲ. (*Maḷe ādare, nāvu hōguvudilla.*) — If it rains, we won't go.

### 2. The Conjunction "But"
* **Origin:** the same word, frozen as a connector.
* **Meaning:** however, but.
* ಮಳೆ ಬರುತ್ತಿದೆ, **ಆದರೆ** ನಾವು ಹೋಗುತ್ತೇವೆ. (*Maḷe baruttide, ādare nāvu hōguttēve.*) — It is
  raining, but we are going.

**How to tell them apart:**
* Attached to the end of the first clause ("X ಆದರೆ (*ādare*), …"), it is "if".
* Starting the second clause, after a complete statement ("X is true. ಆದರೆ (*ādare*) …"),
  it is "but".

## 6. Other "If" Words

| Word | Meaning | Example |
| :--- | :--- | :--- |
| ಒಂದು ವೇಳೆ (*ondu vēḷe*) | supposing, in case | ಒಂದು ವೇಳೆ ನಾನು ಲೇಟ್ ಆದ್ರೆ, ನೀವು ಶುರು ಮಾಡಿ. (*Ondu vēḷe nānu lēṭ ādre, nīvu śuru māḍi.*) — In case I'm late, start without me. |
| ಬೇಕಾದರೆ (*bēkādare*), spoken ಬೇಕಾದ್ರೆ (*bēkādre*) | if you want | ಬೇಕಾದ್ರೆ ನಾನು ಬರ್ತೀನಿ. (*Bēkādre nānu bartīni.*) — I'll come if you want. |
| ಹಾಗಾದರೆ (*hāgādare*), spoken ಹಾಗಿದ್ರೆ (*hāgidre*) | in that case | ಹಾಗಿದ್ರೆ ನಾಳೆ ಮಾತಾಡೋಣ. (*Hāgidre nāḷe mātāḍōṇa.*) — In that case, let's talk tomorrow. |
| ಇಲ್ಲದಿದ್ದರೆ (*illadiddare*), spoken ಇಲ್ಲಾಂದ್ರೆ (*illāndre*) | otherwise | See *Conjunctions*, §5. |
| ಅಂದ್ರೆ (*andre*), formal ಅಂದರೆ (*andare*) | if (someone) says | ನೀವು ಬೇಡ ಅಂದ್ರೆ ನಾನು ಹೋಗಲ್ಲ. (*Nīvu bēḍa andre nānu hōgalla.*) — If you say no, I won't go. |

> **Note:** ಒಂದು ವೇಳೆ (*ondu vēḷe*) only adds "supposing"; the verb still needs
> -ಅರೆ (*-are*). ❌ ಒಂದು ವೇಳೆ ಮಳೆ ಬರುತ್ತೆ… (*ondu vēḷe maḷe barutte…*)

## 7. Common Mistakes

* ❌ ಅವನು ಬರುತ್ತಿದ್ದರೆ (*avanu baruttiddare*) for "if he comes" → ✅ ಅವನು ಬಂದರೆ (*avanu
  bandare*). ಬರುತ್ತಿದ್ದರೆ (*baruttiddare*) means "if he were coming / used to come".
* ❌ ಬರದೆ (*barade*) for "if (one) doesn't come" → ✅ ಬರದಿದ್ದರೆ (*baradiddare*). ಬರದೆ (*barade*)
  means "without coming".
* ❌ ವಿಶ್ರಾಂತಿ ತೆಗೆದುಕೊ (*viśrānti tegeduko*) → ✅ ವಿಶ್ರಾಂತಿ ತೆಗೆದುಕೋ (*viśrānti tegedukō*) —
  take some rest. The familiar command of ಕೊಳ್ಳು (*koḷḷu*) has a long ō.

## 8. Quick Reference

| | Formal | Spoken | Meaning |
| :--- | :--- | :--- | :--- |
| If | ಬಂದರೆ (*bandare*) | ಬಂದ್ರೆ (*bandre*) | if (one) comes |
| If not | ಬರದಿದ್ದರೆ (*baradiddare*) | ಬರದಿದ್ರೆ (*baradidre*) | if (one) doesn't come |
| If had | ಬಂದಿದ್ದರೆ (*bandiddare*) | ಬಂದಿದ್ದಿದ್ರೆ (*bandiddidre*) | if (one) had come |
| Even if | ಬಂದರೂ (*bandarū*) | ಬಂದ್ರೂ (*bandrū*) | even if (one) comes |
| Only if | ಬಂದರೆ ಮಾತ್ರ (*bandare mātra*) | ಬಂದ್ರೆ ಮಾತ್ರ (*bandre mātra*) | only if (one) comes |
| Would have | ಬರುತ್ತಿದ್ದೆ (*baruttidde*) | ಬರ್ತಿದ್ದೆ (*bartidde*) | I would have come |
| Noun "if" | ಡಾಕ್ಟರ್ ಆದರೆ (*ḍākṭar ādare*) | ಡಾಕ್ಟರ್ ಆದ್ರೆ (*ḍākṭar ādre*) | if (one) is / becomes a doctor |

## For Hindi Speakers

* Hindi *agar … to …* uses words; Kannada uses the -ಅರೆ (*-are*) ending and no "then" word.
  Hindi's optional *agar* is closest to ಒಂದು ವೇಳೆ (*ondu vēḷe*).
* Hindi *chāhe … bhī* ("even if") is -ಅರೂ (*-arū*); *jo bhī* ("whoever") is a question word +
  -ಅರೂ (*-arū*): ಯಾರು ಬಂದರೂ (*yāru bandarū*).
* Hindi *agar tum batāte to maĩ madad kartā* matches §4D: the "would" sits on the "then"
  verb, ಸಹಾಯ ಮಾಡ್ತಿದ್ದೆ (*sahāya māḍtidde*).
